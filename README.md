# Data Science yo‘li (PWA)
1. GitHub’da yangi repo oching (masalan, `yol`), Public.
2. Shu papkadagi barcha fayllarni repo ildiziga yuklang (Add file → Upload files).
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
4. 1–2 daqiqadan keyin `https://<username>.github.io/yol/` ochiladi.
5. Telefonda ochib: Chrome → ⋮ → «Ilovani o‘rnatish»; iPhone Safari → Ulashish → «Bosh ekranga qo‘shish».
Yangilash: index.html ni almashtirsangiz, sw.js dagi `ds-v1` ni `ds-v2` ga o‘zgartiring.
